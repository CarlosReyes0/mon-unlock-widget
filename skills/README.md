# OpenClaw Skills

Publish mon-unlock articles from your phone.

**Start here:** [mon-unlock-embed/OPTIONS.md](./mon-unlock-embed/OPTIONS.md) — explains the three setup paths and which to choose.

Most people want **Option B**: phone for writing, MetaMask once for on-chain registration.

Quick install:

```bash
cd mon-unlock-embed && npm install && openclaw plugins install .
```

Then see [mon-unlock-embed/README.md](./mon-unlock-embed/README.md).
