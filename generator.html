Media URL tips
Photos — use a direct image file URL in <img src>:
✅ https://i.postimg.cc/….jpg
✅ https://picsum.photos/800/500
❌ gallery pages like postimg.cc/… or Google Images result links
YouTube — paste into <iframe src> (or use the button):
✅ https://www.youtube.com/embed/VIDEO_ID
✅ watch/share links (auto-converted)
❌ don’t put a YouTube link in <video src>
MP4 / WebM — direct file URL in <video src> (e.g. ends in .mp4).
Blank lines in plain text are kept as paragraph spacing. Iframes allowlisted: YouTube, Vimeo, Loom.
