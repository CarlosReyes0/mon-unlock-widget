# DeltaV Weekly Update Template

**Canonical guide:** [Pareen (@pareen) on X](https://x.com/pareen/status/1913648566976860173) — *How to write a great Weekly Update* (asks + copyable template).

Use this skeleton for DeltaV / Monad program weekly summaries. Agents: see `.cursor/rules/deltav-weekly-update.mdc`.

---

## Copy-paste skeleton

```
Weekly Update – MON Unlock Widget 🧠 Week #[XX]

Let’s go👇

1. TL;DR
Quick wins ✅
Challenges 😤
What’s next 🔮

2. Highlights
• 🧪 [Launched X feature / Signed Y customer / Closed Z deal]
• 📈 [User growth %, revenue milestone, etc.]
• 🤝 [Partnerships, hires, shoutouts]

3. Lowlights
• 😓 [Missed goals / Tech issues / Drop in metrics]
Being transparent so we can fix fast.

4. Core Metrics
• Users: [X → Y]
• MRR: [$X → ]
• DAU: [10k]
(Pick stage-appropriate metrics — e.g. unlock txs, registered articles, publishers, MON volume.)

5. This Week’s Focus
→ [Top priorities for the week ahead]
→ [Experiments / Launches / Learning goals]

6. Asks
• Know anyone hiring a [X]?
• Got intros to [target customers, VCs, advisors]?
• Feedback welcome on [feature, pitch, design]

7. Shoutouts
🙏 [Teammates, advisors, users, friends who helped]
Credit where it’s due.
```

## Section reminders (from Pareen)

| Section | Job |
|--------|-----|
| **TL;DR** | 10-second skim; most people stop after the first lines |
| **Highlights** | Show motion — shipped work, traction, belief compounds |
| **Lowlights** | Own what broke; invite help; operator signal |
| **Core Metrics** | ~3 hard numbers, tracked every week |
| **This Week’s Focus** | One clear plan; next highlight proves execution |
| **Asks** | Specific and actionable (not “know anyone?”) |
| **Shoutouts** | Credit helpers; social fuel |

A weekly update is a ritual: document the journey, build trust, compound attention — not just a status dump.
