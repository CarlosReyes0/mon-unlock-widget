# Posting

On Substack you write, hit **Publish**, and it’s up.

That’s the whole product. Not a form. Not copy-paste HTML.

---

**Today:** Create embed → fill a bunch of boxes → copy code.

**Should be:** Title. The piece. **Publish.** Then people can read it here.

Price can stay $0.50. The link can come from the title. The start of the piece is free; the rest is paid. Writer doesn’t set any of that while writing.

Copy-an-embed is for later, if they have their own site.

Done when posting feels like Substack, not like building a widget.
